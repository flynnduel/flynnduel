# Party Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A room-code party hub, joinable from anywhere through a Cloudflare quick tunnel, that hosts faithful versions of Wavelength, Codenames and Secret Hitler with avatars, a next-game vote, teams, talk timers, party points, a leaderboard and an end-of-night awards show.

**Architecture:** One Node process. `rooms.js` holds many `Room`s; each `Room` owns players, lobby state, stats and at most one running game engine. Engines are pure, synchronous and deterministic (`rng`, `now` injected) behind one interface; only `Room` touches sockets (via callbacks from `index.js`). The browser client is plain ES modules (no build step) with SVG art and Web Audio sounds; avatars are rendered server-side as SVG with DiceBear.

**Tech Stack:** Node ≥ 20 (CommonJS server), express 5, socket.io 4.8, qrcode-terminal 0.12, `cloudflared` 0.7 (MIT; ESM — load via dynamic `import()`), `@dicebear/core` 9 + `@dicebear/collection` 9 (MIT code; use only the **lorelei** and **notionists** styles, artwork CC0), `@fontsource/fredoka` 5 (OFL), dev: socket.io-client 4.8. Tests: `node --test`. Browser checks: global Playwright at `/opt/node22/lib/node_modules/playwright`, Chromium `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.

**Spec:** `docs/superpowers/specs/2026-10-04-party-hub-design.md` (§ numbers below refer to it).

## Global Constraints

- All code in `party-hub/`; commands run from there. `npm test` = `node --test`.
- Engine and `Room` methods return `{ ok: true, ... }` or `{ ok: false, error: string }`; never throw on user input; non-string text → `''`; unknown ids → `'Not now'`.
- Room code: 4 letters from `ABCDEFGHJKLMNPQRSTUVWXYZ` (no I, O). Max **12** players/room. Empty rooms deleted after **30 min** with nobody connected.
- Names 1–16 chars, unique case-insensitively among connected players in a room (`'That name is taken'`).
- Photo avatars: `data:image/jpeg;base64,` only, decoded ≤ **40 KB**, client-resized to **160×160**.
- Chat: 1–140 chars, 1 msg / 1000 ms / player, last 50 kept; paused during talk phases (`'Chat is paused — talk it out!'`).
- Vote: resolves when all connected voted or **15 s** after first vote; ties random; **3 s** countdown.
- Timer modes: `chill` ×1.5, `normal` ×1, `spicy` ×0.6, `off` (no timers, no +30 s). Base: Codenames guess **120 s**, Wavelength dial **90 s**, Wavelength left/right **30 s**, Secret Hitler discussion **90 s**. +30 s once per turn.
- Points: win **+3**, MVP **+1**. Ranks: Rookie 0, Contender 3, Sneaky 8, Beast 15, Legend 25, Party God 40.
- Secret Hitler credit text exactly: `Secret Hitler by Goat, Wolf & Cabbage — CC BY-NC-SA 4.0`. No swastikas or real Nazi insignia anywhere.
- All player text rendered with `textContent`/escaping, never as HTML.

## Review Focus

1. **The tunnel fails on Flynn's Mac** (binary download blocked, offline, Cloudflare hiccup) — the server must keep running and print the LAN URL with a reason. Test: Task 2 `tunnel failure falls back to LAN`.
2. **Phone sleeps mid-game and rejoins** — same room, seat, team and secret info (role, key, target). Test: Task 2 smoke `rejoin restores seat and secrets`.
3. **Host leaves mid-game** — host crown moves; game keeps running; new host can End party / force-start. Test: Task 1 `host passes on disconnect`.
4. **Secret Hitler with players dropping** — a disconnected President/Chancellor must not freeze the game: the host gets **Skip** for that step after the talk timer (or 60 s when timers are off) which follows the official chaos-safe path (failed election). Test: Task 8 `host skip on absent president counts as failed election`.
5. **Two people dragging the Wavelength dial at once** — last write wins, everyone converges to the same position, no oscillation storm. Test: Task 6 `concurrent dial moves converge` + rate limit in Task 2.

### Engine interface (all three games)

```
create({ players:[{id,name}], teams:{A:{ids,name,color},B:{…}}|null, leadOrder:{A:[id…],B:[id…]}|null,
         settings:{ timerMode, packs:[packId…] }, rng, now }) → Engine
engine.act(playerId, action: { type, ...args }) → { ok } | { ok:false, error }
engine.view(playerId) → object   // unknown id = spectator public view
engine.nextWakeAt() → number|null
engine.tick() → boolean           // advance timeouts; true if changed
engine.result() → null | { winners:[id], mvp:id|null, stats:[{ type, playerIds:[id], value? }] }
engine.talking() → boolean        // true during talk phases → Room pauses chat
engine.turnId() → string          // changes every turn; used for high-five limits
engine.reconnect?(playerId) / engine.disconnect?(playerId)   // optional hooks
```

Stat `type`s (used by points/awards): `led`, `psychicBullseye`, `bullseye`, `miss` (value = distance), `lrCorrect`, `assassin`, `turnEndingReveal`, `clueYield` (value = count), `rejectedLiberal`, `fascistElected`, `teamkill`, `hitlerWin`, `kingmaker`, `maxLead` (value = margin, losing team), `mvpTie` not used.

### Task 6: Wavelength engine (spec §6)

**Files:** create `server/games/wavelength.js`; register in `games/index.js`; test `test/wavelength.test.js`; extend smoke.

**Interfaces / rules to encode:**
- `scoreDial(dial, center) → 0|2|3|4` with bands `|dial − center| ≤ 2.25 → 4`, `≤ 6.75 → 3`, `≤ 11.25 → 2`, else 0 (5 bands × 4.5).
- Team mode phases: `huddle` (1500 ms auto) → `clue` (Psychic `clueGiven`) → `dial` (timer `phaseMs(90000)`; actions `dial {pos 0–100}` by active team non-Psychics, `lock` by any active non-Psychic; timeout locks) → `leftRight` (timer `phaseMs(30000)`; `call {side:'left'|'right'}` by opposing members, changeable; timeout/all-called resolves; majority; tie/no calls = none) → `reveal` (3000 ms auto) → next turn or `done`. `extend` once per turn by active team (not when mode off).
- Scores start `{ A:0, B:1 }` (first team is `A`, chosen randomly by swapping labels at create). Catch-up: if the active team scored 4 and is still behind after scoring → same team again (next Psychic in rotation). End check after each reveal: any team ≥ 10 → higher wins; tied → sudden death: each team takes one turn; after both, check lead; repeat.
- Co-op mode (2–3 players, `teams` null): 7 cards (+1 per 4-pointer), Psychic rotates through all players, everyone else can dial, no left/right; `result` rating band and win if total ≥ 16.
- Views: target `center` only in the current Psychic's view during `clue`/`dial`/`leftRight`, everyone at `reveal`; spectrum visible to all; `phaseEndsAt`, `turnId`, scores.
- Stats: `led` (Psychic), `psychicBullseye` (Psychic on 4), `bullseye` (active team ids on 4), `miss` value = `|dial − center|` for active team ids, `lrCorrect` (opposing members who chose the majority side when correct), `maxLead` for losing team at end.
- MVP: Psychic with highest average points per clue (ties → more clues, then earliest join).

**Files:** create `server/games/codenames.js`; register; test `test/codenames.test.js`; extend smoke.

**Interfaces / rules to encode:**
- Board: 25 `drawWords`; key: starting team (random) 9, other 8, 7 `bystander`, 1 `assassin`, shuffled.
- Phases per turn: `clue` (active spymaster `clue {count: 0–9 | 'inf'}`) → `guess` (timer `phaseMs(120000)`): `mark {index}` (operative, toggles their avatar mark), `reveal {index}` (operative; client sends after 1 s hold), `endTurn` (allowed after ≥ 1 reveal this turn), `extend`. Guess limit: `count + 1` for 1–9; unlimited for 0 and `'inf'`.

- Views: key visible to both spymasters (and everyone after `done`); operatives/spectators see only revealed identities; marks visible to own team only.
- Stats: `led`; `assassin` (revealer); `turnEndingReveal` (revealer when reveal ended own turn by bystander/opponent); `clueYield` value = correct own-agent reveals in that turn for that clue (spymaster); `maxLead` for the losing team: the largest value, over the game, of (opponent's agents remaining − own agents remaining) while positive.
