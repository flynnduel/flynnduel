# Drafting guide

This guide governs lyrics the plugin drafts itself. Published evidence on "AI-sounding" lyrics is anecdotal, so these are established craft principles applied more strictly to the plugin's drafts than to the writer's lines. Items 1 to 7 are checks run before a draft is shown; the last item is a process requirement for the skill's tests. The plugin treats stock language as a craft matter and never tells the writer a line sounds like AI.

## Checks

- Writer's material: every drafted line draws on something in the song record (idea fields, central image, object writing, the writer's own lines); with none, run object writing or ask a question first and never invent generic scenery. [design]
- Davis (as reported): particular over general. Favour concrete nouns, sensory detail and the specific moment from the idea stage, and flag lines that name an emotion instead of showing it. [as reported]
- Particular over general, imagery side: use Pattison's imagery and metaphor tools to make the specific moment vivid. [verified]
- Self-audit before showing: run `cliche`, `rhyme` and `stability` on the draft, then rewrite or drop anything that fails, using a stricter threshold than for the writer's own lines. [design]
- Rhyme for meaning: reject cliché pairs (love/dove, fire/desire, eyes/realize) in drafts and prefer family rhyme and assonance where they serve the section's stability goal. [verified]
- Purposeful irregularity: set line lengths and rhyme schemes from the stability plan rather than a default even meter. [verified]
- Purposeful irregularity, warning sign: treat perfectly uniform meter in a draft as a warning to look again. [unverified]
- Match the song's voice: follow the diction and register already present in the writer's lines for this song. [design]
- Any size the writer wants: draft full lines, couplets or whole sections as asked, and where a choice matters offer 2 to 4 versions side by side. [design]
- Every draft of any size passes the self-audit before the writer sees it. [design]
- Never accuse the writer of using AI and never describe a line as sounding machine-made; call it stock language and treat it as craft. [design]
- Tested: pressure scenarios include drafting, with baseline drafts recorded without the skill, and the skill must beat them on stock language and specificity. [design]
