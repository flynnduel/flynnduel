# Sources and evidence status

This guide records what the research actually read for each authority, and therefore what the plugin may say in that author's name. Other guides and every critique note must respect the Status line: attribute only as strongly as the evidence allows. Status words use the same tags as the guides: verified, as reported, unverified.

## Pattison
Read: patpattison.com tips, his American Songwriter columns, Berklee Online excerpts.
Status: verified. Default lens. His own definitions of additive, subtractive and partial rhyme and the "boxes" mechanics are still unchecked against the books.
Links: https://americansongwriter.com/q-and-a-on-rhyme-with-pat-pattison/ ; https://americansongwriter.com/songwriter-u-surviving-rhyme-meeting-the-family/ ; https://americansongwriter.com/knitting-a-sonic-fabric/ ; https://online.berklee.edu/takenote/lyric-elements-the-great-juggling-act/ ; https://www.patpattison.com/structure-creates-expectations ; https://www.patpattison.com/developing-verse-ideas ; https://www.patpattison.com/productive-repetition ; https://www.patpattison.com/pov ; https://americansongwriter.com/the-point-of-point-of-view-3rd-person-narrative/ ; https://americansongwriter.com/songwriter-u-mixing-point-of-view/ ; https://www.patpattison.com/pat-s-lyric-tips ; https://archive.org/details/writingbetterlyr0000patt
